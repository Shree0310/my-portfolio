# Tailwind CSS Basics
Tailwind CSS is a utility-first CSS framework that provides low-level utility classes to build custom designs
directly in your HTML. Instead of writing custom CSS, you compose pre-built classes to create your design.

# Common Utility Categories
## Spacing: Tailwind uses a consistent spacing scale (0-96) where each unit equals 0.25rem (4px).

p-4 adds padding of 1rem (16px)
m-2 adds margin of 0.5rem (8px)
px-6 adds horizontal padding, py-3 adds vertical padding

## Colors: Colors come in shades from 50 (lightest) to 950 (darkest).

bg-blue-500 for background color
text-red-600 for text color
border-gray-300 for border color
